# Released Mem-GF baseline

The benchmark uses Jin-Duk Park and Won-Yong Shin's Mem-GF, IEEE TKDE (2026), [DOI](https://doi.org/10.1109/TKDE.2026.3704986). Fetch the pinned files from [the upstream repository](https://github.com/jindeok/Mem-GF) with `python scripts/download_reference.py` from this repository root. `configs/reference.json` records the exact commit, file checksums, and required definitions. The evaluation loader uses the original definitions after SHA-256 verification. Upstream files and any applicable upstream terms remain separate from this artifact.
