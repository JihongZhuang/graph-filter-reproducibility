# Code availability

This review artifact provides the streaming polynomial recurrence, a pinned baseline loader, prepared-split conversion and hash checks, full-catalog evaluation, portable CPU timing, and the aggregate evidence underlying Tables 1–6 and Figures 1–3. See the [README](README.md) for commands and the [Mem-GF baseline notes](baselines/README.md) for third-party attribution.

The reference scoring definitions are obtained directly from the Mem-GF project at the frozen commit and checked by hash. That upstream source and its terms are separate. The historical timing tables are recomputed from the 44 archived run summaries. The portable benchmark can generate new observations and has its own process boundary. The original environment, aggregate timings and paired statistics are supplied as evidence. Original run logs and individual output arrays remain local.
